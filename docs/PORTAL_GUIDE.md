# Guardian's Embrace Portal Guide

This is a simple guide for everyone using the Guardian's Embrace Volunteer Management Portal.

The goal of this portal is to help us stay organized, keep projects moving, and make it easier for volunteers, team leads, and admins to work together.

## What This Portal Is For

You can use this portal to:

- submit your weekly work updates
- see what projects are happening
- join projects you want to help with
- track tasks and work items
- assign work and collaborate with others
- manage users and settings if you have the right access

## First Time Using The Portal

When you log in for the first time:

1. Sign in with your approved Google account.
2. Set your display name if the portal asks for it.
3. Open your dashboard and get familiar with the main sections.

The main sections are:

- `Dashboard`
- `Submissions`
- `Projects`
- `Admin`

Most people will mainly use `Dashboard`, `Submissions`, and `Projects`.

## The Best Way To Use The Portal

The portal works best when people use it regularly and keep things updated.

A good routine is:

1. Check your dashboard.
2. Submit your weekly update on time.
3. Look at the projects you are part of.
4. Request access to projects you want to help with.
5. Keep work items updated so others know what is happening.
6. Report bugs or improvement ideas when you see them.

## What Volunteers Can Do

If you are a volunteer, you can:

- view your dashboard
- create and submit weekly updates
- save drafts and come back later
- see your own submission history
- open projects and see what is happening
- create new projects
- request access to projects
- request to become the lead of a project
- request deletion of a project
- work on project tasks after you are added to a project

Volunteers are the main day-to-day users of the portal.

Best practice for volunteers:

- submit honest and clear weekly updates
- mention blockers if something is slowing you down
- request project access instead of waiting silently
- use project work items to stay aligned with the team

## What Team Leads Can Do

If you are a team lead, you can do everything a volunteer can do, and also help run project work.

Team leads can:

- create projects
- update project details
- add and remove project members
- create work items
- assign work items
- assign one work item to more than one person
- approve or decline project access requests
- approve or decline project lead requests
- approve or decline project deletion requests

Team leads help keep projects moving.

Best practice for team leads:

- keep project boards clean and current
- assign work clearly
- avoid leaving work items unowned for too long
- approve or decline join requests quickly
- break big work into smaller work items

## What Admins Can Do

Admins have full access across the portal.

Admins can:

- manage users
- invite new people
- change user roles
- activate or deactivate accounts
- review submissions
- send reminder emails
- manage settings and forms
- manage delegated access
- view audit logs

Admins help keep the portal healthy, secure, and organized.

Best practice for admins:

- keep user access clean
- only give extra privileges when needed
- review submissions regularly
- keep settings and forms up to date
- use audit logs when something needs to be checked

## What Extra Privileges Mean

Some users may get extra permissions without becoming full admins.

This is called delegated access.

For example, someone might be allowed to:

- review submissions
- manage projects
- manage invites
- edit settings
- view users
- manage delegated access

This helps admins share work safely.

If you have extra privileges, use them carefully and only for the areas you were trusted with.

## How To Submit Your Weekly Work

This is one of the most important parts of the portal.

To submit your weekly update:

1. Open `Submissions`.
2. Click `New Submission`.
3. Fill in your work for the week.
4. Add blockers, notes, or files if needed.
5. Save a draft if you are not ready.
6. Submit when it is complete.

Try to include:

- what you worked on
- what you are working on now
- what you plan to do next
- how many hours you spent
- anything blocking you

Good weekly updates help everyone understand progress and know where support is needed.

## How To Use Projects Well

Projects are there to make collaboration easier.

You can:

- view project boards
- see who is involved
- request access to join
- track work items
- take or join work items if you are on the project

If you want to help on a project:

1. Open the project.
2. Click `Request Access`.
3. Add a short note about how you want to help.

If you already have access:

- check the work items
- update the status of your work
- join shared work when needed
- keep descriptions clear so others understand what is going on

## How To Use Work Items Well

Work items are best used for:

- bugs
- features
- fixes
- research
- content work
- follow-ups
- project handoffs

A good work item should clearly say:

- what needs to be done
- who is involved
- what status it is in
- when it is due, if there is a deadline

If more than one person is working on something, assign multiple people instead of hiding the teamwork.

## If Something Is Broken

If you find a bug, do not ignore it.

You can report it in two places:

- GitHub, for tracking the technical issue
- the portal itself, as a project work item

The GitHub repository is:

- `https://github.com/Guardiansembrace/guardians-embrace-volunteer-portal`

When reporting an issue, try to include:

- what happened
- what you expected to happen
- the steps to reproduce it
- screenshots if helpful

If the issue belongs to an active portal project, also create a work item for it in the portal so the team can track and assign it.

## If You Want To Help Improve The Portal

You do not have to wait to be asked.

If you notice:

- a bug
- a confusing workflow
- a missing feature
- something that could be simpler

you can:

1. raise a GitHub issue
2. create a portal work item
3. help fix it if you want to contribute

If you want to work on the code, follow [CONTRIBUTING.md](/c:/Guardian's%20Embrace%20Dev/guardians-volunteer-portal/CONTRIBUTING.md).

## Common Situations

### I Can See A Project But I Cannot Work On It

You probably need to request access or be added to the project by someone managing it.

### I Was Invited But I Still Look Like Pending Login

That usually means you have not completed your first sign-in yet.

### I Cannot Access The Admin Section

That usually means you are not a full admin and have not been given delegated access for that area.

### My Submission Is Locked

That usually means:

- the submission window is closed
- the submission was already reviewed
- or late submissions are not allowed right now

### I Need More Access

Ask an admin whether you need:

- project access
- delegated access
- or a role change

## A Good Portal Culture

The portal works best when people use it in a simple and honest way.

That means:

- keep updates clear
- keep projects current
- do not leave tasks unclear
- report bugs early
- share ownership
- help improve the system as we go

This portal is not just a tool. It is a shared working space for the whole team.
